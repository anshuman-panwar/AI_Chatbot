# 🤖 AI Chatbot

A simple and interactive chatbot built with **Python** and **Streamlit**.

This project is my first step toward building a more advanced AI-powered chatbot. It currently uses predefined responses and Streamlit's session state to maintain the conversation during a session.

## ✨ Features

- 💬 Interactive chat interface
- 🧠 Conversation history using Streamlit Session State
- ⚡ Instant responses
- 🔤 Case-insensitive message matching
- 🎨 Clean Streamlit interface
- 🐍 Built with Python
- 🔒 Environment variables kept private with `.gitignore`

## 🛠️ Technologies Used

- **Python 3.11**
- **Streamlit**
- **python-dotenv**
- **Git & GitHub**
